# Real-Time Character Counter

A simple JavaScript project built as part of the freeCodeCamp curriculum. It counts characters in real time as the user types.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 Features
- Real-time character counting
- Updates automatically as you type

## 👩‍💻 What I Learned
- Handling user input with JavaScript
- Working with DOM events
- Updating the DOM dynamically
